Konverter Pesanan Shopee → Invoice

Ubah file "Order All" Shopee jadi format invoice siap upload — otomatis, tanpa ubah data mentah.

1Upload file pesanan
2Cocokkan nama produk
3Cek hasil
4Download

1. Upload file mentah dari Shopee

Drag & drop file export "Order All" (.xlsx) dari Seller Centre Shopee ke sini.

📥 Tarik & lepas file di sini, atau klik untuk pilih file
Format: .xlsx / .xls / .csv

Pesanan berstatus Belum Bayar dan Batal otomatis dikecualikan dari sheet Invoice. Batal tetap masuk sheet & draft WA terpisah di bawah.

2. Cocokkan nama produk ke nama template

Kolom kiri = nama produk asli dari Shopee (dari file pesanan). Kolom kanan otomatis terisi kalau sudah cocok dengan daftar produk (tombol "📄 Daftar Produk" / "🗂️ Data Jurnal" di pojok kanan atas) — sisanya bisa diisi manual (autocomplete tersedia kalau data Jurnal sudah diupload).

4. Download hasil convert

File Excel berisi sheet Invoice saja (siap upload) — pesanan Belum Bayar dan Batal tidak ikut diekspor. Preview pesanan batal & draft WA di atas tetap bisa dipakai untuk follow-up manual.
